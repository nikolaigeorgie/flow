FAQ

Which Macs does it run on?

Any Apple Silicon Mac (M1 or newer) on macOS 14 Sonoma or later. 16 GB of memory or more is recommended; the two models use about 8 GB while loaded.

Why does it need Accessibility and Input Monitoring?

Input Monitoring lets it notice Ctrl+Space from any app, and Accessibility lets it paste the text for you. macOS asks once; Flow restarts by itself after you grant them.

Is anything sent to the internet?

Only the one-time model download from Hugging Face. After that Flow runs fully offline. You can check with lsof -nP -i | grep python.

Why don't I see the menu bar icon?

On MacBooks with a notch, macOS hides extra menu bar icons behind it. Hold ⌘ and drag the Flow mic icon further right. "Flow is on" also appears on screen whenever it starts.

Why build it on my Mac instead of downloading an app?

The installer builds and signs Flow on your own machine, so macOS trusts it without an "unidentified developer" warning, and you can read every line of code it runs.

How do I uninstall?

Run ~/.flow/uninstall.sh. Add --all to also remove your dictionary and the ~8 GB of models.
